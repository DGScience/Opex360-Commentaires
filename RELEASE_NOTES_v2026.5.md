# v2026.5

Correctif de l’importation des préférences : l’import fonctionne depuis un onglet persistant, afin que Firefox ne ferme plus la fenêtre de l’extension lors de l’ouverture du sélecteur de fichier.

Fonctions : masquage des auteurs et branches de commentaires, mise en évidence d’auteurs appréciés, export et import JSON des préférences.

**Installation** : extension non signée. Pour un essai temporaire, décompresser l’archive, ouvrir `about:debugging#/runtime/this-firefox` puis charger le fichier `manifest.json`. Une installation permanente nécessite une signature Mozilla.
