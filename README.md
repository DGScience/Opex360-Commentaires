# Opex360 — Filtre de commentaires

Extension Firefox pour filtrer les commentaires du site [Opex360](https://www.opex360.com/).

**Version actuelle : 2026.5**

## Fonctionnalités

- Masquer les commentaires d'un auteur et les réafficher temporairement.
- Masquer toute une branche de réponses.
- Mettre en évidence les commentaires des auteurs appréciés avec une couleur.
- Gérer les auteurs masqués et colorés dans la fenêtre de l'extension.
- Exporter et importer les préférences au format JSON.

Les préférences restent dans le stockage local du navigateur. Aucune donnée n'est envoyée ailleurs.

## Installation temporaire sous Firefox

1. Télécharger et décompresser les sources.
2. Ouvrir `about:debugging#/runtime/this-firefox`.
3. Choisir **Charger un module complémentaire temporaire**.
4. Sélectionner `manifest.json`.

Cette installation est temporaire : Firefox supprime le module au redémarrage. Une installation permanente sur Firefox standard nécessite une signature Mozilla.
